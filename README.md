# Piyush Sharma — Portfolio Website

## Files

- `index.html` — website structure
- `style.css` — responsive design and theme styling
- `script.js` — dynamic skills, projects, filters, animations, navigation, and theme switcher
- `assets/resume.pdf` — add your resume PDF here

## How to customize

Open `script.js` and edit:

- `portfolioData.skills`
- `portfolioData.projects`
- `portfolioData.experience`

Then edit the email, LinkedIn URL, and text inside `index.html`.

## Publish on GitHub Pages

1. Upload all files to the root of `piyush0920.github.io`.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Save.

Your website will be available at:

https://piyush0920.github.io
