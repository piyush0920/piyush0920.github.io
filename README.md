# Piyush Sharma — Hybrid Data Analytics × GenAI Portfolio

## Included
- `index.html` — page structure and content
- `style.css` — dark-first purple design with light-mode support
- `script.js` — dynamic skills, project cards, filters, experience timeline, theme switcher, mobile navigation, and scroll animations
- `assets/` — place resume PDFs and project screenshots here

## Add your resumes
Place your PDFs in `assets/` using these names:
- `resume-data-analytics.pdf`
- `resume-genai.pdf`

The first file is linked from the hero section. You can add a second resume button later if desired.

## Publish
Upload all files to the root of `piyush0920.github.io`, then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`
